# How to post on the blog

1. Add `src/content/blog/your-slug.md` with frontmatter:

```yaml
---
title: "Your title"
description: "Meta description for SEO."
date: 2026-10-18
updated: 2026-10-18
readMinutes: 5
author: Image Identifier
---
```

2. Write Markdown body (link to `/` for the tool; no detection internals).
3. Commit, push — Pages rebuilds `/blog/your-slug/`.

Day-1 post: `/blog/free-ai-image-checker-no-upload/`  
Day-2 post: `/blog/how-accurate-are-ai-image-detectors/`  
Day-3 post: `/blog/check-screenshot-or-social-photo-for-ai/`
