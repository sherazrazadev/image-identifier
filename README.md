# Image Identifier

Free, browser-local image forensics / provenance tool (C2PA + metadata + optional ML).

**Suggested site:** https://image.tommyfx.pk  
**Docs / tickets:** [`docs/tickets.md`](docs/tickets.md) · **SOP:** [`docs/website-image-checker.txt`](docs/website-image-checker.txt)

Stack: Astro (static) · JavaScript · Tailwind · React islands · Cloudflare Pages.

## Scripts

```bash
npm install
npm run dev      # local development
npm run build    # output → dist/
npm run preview  # preview production build
```
